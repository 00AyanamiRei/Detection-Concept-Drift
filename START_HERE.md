## 🔬 ЯКІ МЕТОДИ ВИКОРИСТАНІ

### 1. Формальний аналіз концептів (FCA)

**Що це:**

- Математичний метод аналізу даних на основі теорії ґрат
- Перетворює дані у формальні поняття та їх ієрархію

**Формальний контекст K = (G, M, I):**

- G - множина об'єктів (екземпляри)
- M - множина атрибутів (ознаки)
- I - відношення "об'єкт має атрибут"

**Формальне поняття (A, B):**

- A (extent) - множина об'єктів
- B (intent) - множина атрибутів
- Властивість: об'єкти в A мають усі атрибути з B

**Концепт-гратка:**

- Упорядкована множина всіх понять
- Утворює ґрату за операціями зустрічі (⊓) та з'єднання (⊔)

### 2. Детекція дрейфу концепту

**Гіпотеза:**
Коли відбувається концептуальний дрейф, структура концепт-гратки змінюється.

**Наш підхід:**

1. Будуємо ґрату L_t для поточного вікна
2. Порівнюємо L*t з L*{t-1} за 3-компонентною метрикою
3. Обчислюємо ΔL*t = 1 - Similarity(L_t, L*{t-1})
4. Застосовуємо адаптивний поріг: θ_t = μ + α·σ
5. Якщо ΔL_t > θ_t → виявлено дрейф

**Метрика подібності гратик:**

```
Sim(L1, L2) = α·Sim_concepts + β·Sim_hierarchy + γ·Sim_structure

де:
α = 0.4 - вага подібності понять (Jaccard на extent+intent)
β = 0.3 - вага подібності ієрархії (граф ребер)
γ = 0.3 - вага структурної подібності (кількість, глибина)
```

### 3. Адаптивне пороговування

**Проблема:**
Статичний поріг не адаптується до характеристик даних.

**Вирішення:**

```
θ_t = μ + α·σ

μ - середнє значення ΔL за останні 10 вікон
σ - стандартне відхилення
α - коефіцієнт (за замовчуванням 2.0 - статистичне правило 2-sigma)
```

### 4. Baseline детектори для порівняння

#### DDM (Drift Detection Method, Gama et al. 2004)

- Монітує коефіцієнт помилок p та його стандартне відхилення
- Виявляє дрейф коли p_t + 2·σ_t > p_w + 2·σ_w

#### EDDM (Early Drift Detection Method, Baena-García et al. 2006)

- Вдосконалення DDM
- Використовує дистанцію між помилками замість частоти помилок
- Раніше виявляє градуальний дрейф

#### ADWIN (Adaptive Windowing)

- Адаптивне вікно з автоматичною настройкою розміру
- З бібліотеки River

### 5. Метрики оцінювання

**Precision:**

- Частина виявлених дрейфів, які справді мали місце
- Formula: TP / (TP + FP)
- Важливо для зменшення false alarms

**Recall:**

- Частина справжніх дрейфів, які були виявлені
- Formula: TP / (TP + FN)
- Важливо для повноти детекції

**F1-Score:**

- Гармонійна середина Precision та Recall
- Formula: 2 × (Precision × Recall) / (Precision + Recall)

**Detection Delay:**

- Середня кількість екземплярів від справжнього дрейфу до виявлення
- Менше = краще

## 🏗️ ЯК ЦЕ ПРАЦЮЄ

### Архітектура в одному малюнку

```
Потокові дані
    ↓
[StreamReader] - читання екземплярів
    ↓
[SlidingWindow] - накопичення W екземплярів
    ↓
[DataPreprocessor] - EMA + binarization
    ↓ (бінарна матриця W × M)
[FormalContext] - контекст (G, M, I)
    ↓
[ConceptLattice] - ПОВНА гратка (КРИТИЧНЕ!)
    ↓ (Lattice_t та Lattice_{t-1})
[LatticeSimilarityCalculator] - обчислення подібності
    ↓ (Similarity, ΔL_t)
[FCADriftDetector] - адаптивний поріг + класифікація
    ↓ (DriftEvent)
[DriftEvaluator] - розрахунок метрик
    ↓
[ExperimentLogger] - CSV/JSON зберігання
    ↓
[plot_delta_L] - графіки
    ↓
Результати в experiments/results/
```

### Основний цикл (pseudocode)

```python
detector = FCADriftDetector(theta=0.4, alpha=2.0)
delta_L_history = []

for window in sliding_windows(stream, window_size=100):
    # 1. Бінаризація
    binary_matrix = preprocessor.preprocess(window)

    # 2. Побудова гратки
    context = FormalContext(binary_matrix)
    lattice_t = ConceptLattice()
    lattice_t.build_from_context(context)

    # 3. Порівняння
    similarity = calculator.compute_similarity(lattice_prev, lattice_t)
    delta_L_t = 1 - similarity
    delta_L_history.append(delta_L_t)

    # 4. Адаптивне пороговування
    if len(delta_L_history) >= 10:
        mu = mean(delta_L_history[-10:])
        sigma = std(delta_L_history[-10:])
        theta_adaptive = mu + 2.0 * sigma
    else:
        theta_adaptive = 0.4

    # 5. Детекція дрейфу
    if delta_L_t > theta_adaptive:
        drift_type = classify_drift(delta_L_t, delta_L_history)
        drift_event = DriftEvent(instance_id, drift_type, confidence)
        drifts.append(drift_event)

    # 6. Оновлення
    lattice_prev = lattice_t
```
